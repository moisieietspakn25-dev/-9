
# Лабораторна робота №9
## Реалізація та порівняння алгоритмів сортування

N = 17, K = 20, a = 2, b = 1, c = 2

**Студент:** Мойсєєць Павло Андрійович

**Група:** КН-3/1

### 1. Реалізовані алгоритми

1. Сортування бульбашкою з прапорцем.
2. Сортування злиттям знизу вгору.
3. Гібридне сортування злиттям та вставками.

### 2. Персональні параметри

- N = 17
- K = 20
- a = 2
- b = 1
- c = 2
- Діапазон чисел: [0; 400]
- Генератор: Random(17)
- Кількість обмінів майже відсортованого масиву: 20
- Пороги гібридного алгоритму: 1, 4, 16, 43.

### 3. Трасування сортування

Для трасування використовується перші 6 елементів
основного масиву.

Алгоритм: сортування бульбашкою з прапорцем.

У програмі реалізовано порівняння сусідніх елементів.
Якщо лівий елемент більший за правий, вони міняються
місцями.

Таблиця трасування заповнюється за результатами
покрокового виконання програми.

### 4. Порівняння алгоритмів

Перевіряються чотири типи входу:
- випадковий;
- відсортований;
- відсортований навпаки;
- майже відсортований.

Для кожного алгоритму вимірюються порівняння
та переставляння.

### 5. Додаткове завдання

Реалізовано гібридне сортування.

Використовуються чотири пороги:
1, 4, 16, 43.

Малі ділянки сортуються вставками,
а великі об'єднуються алгоритмом злиття.

### 6. Перевірка стабільності

Перевіряється збереження порядку студентів
з однаковими балами.

Додатково порівнюються:
- Array.Sort;
- OrderBy.

### 7. Перевірка крайових випадків

Перевіряються:
- порожній масив;
- один елемент;
- два елементи в порядку;
- два елементи навпаки;
- однакові елементи;
- два різних значення.

### 8. Висновок

Під час лабораторної роботи було реалізовано
три алгоритми сортування мовою C#.

Було досліджено кількість порівнянь,
переставлянь та час виконання алгоритмів.

Встановлено, що прості алгоритми ефективні
для невеликих або майже впорядкованих масивів,
а сортування злиттям має стабільну складність
O(n log n).

Гібридний алгоритм поєднує сортування вставками
для малих ділянок та злиття для великих.

Також було перевірено стабільність алгоритмів
та правильність результатів.
